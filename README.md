# Описание: данный проект нужен для удобства выполнения задач и их тестирования.

Тестирование useSWR: на странице '/', есть 3 варианта проверки

1ый простой тест с выполнением запроса на сервер

2ой для нескольких запросов с разных компонентов, смотрим не делается ли 2 запроса, то есть работает ли кеш, так как запрос идет по одному клчу

3ий тут используем сет интервал для триггера слайса, смотрим не отрабатывает ли запрос много раз из-за ререндеров компонентов которые на странцие и который также содержат запросы с одним одинаковым ключом и одним уникальным

# Клонируйте проект

git clone git@github.com:avakov987/bench.git
cd <папка-проекта>

# Установите зависимости

npm install

# Запуск dev сервера

npm run dev
